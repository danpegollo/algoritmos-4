# Lógica Condicional em Python

Repositório com exercícios desenvolvidos para praticar lógica de programação e estruturas condicionais utilizando Python.

## Exercícios

### 1. Cálculo de Bônus Salarial
Programa que calcula o bônus e o salário final de um funcionário com base no tempo de trabalho.

### 2. Cálculo de Média Escolar
Programa que calcula a média ponderada de um aluno e informa se ele foi aprovado ou reprovado.

### 3. Decomposição de Cédulas
Programa que calcula a quantidade mínima de notas necessárias para representar um valor.

### 4. Sistema de Combate com Dados
Programa simples de combate que utiliza números aleatórios para definir vencedor e calcular dano.

## Assuntos praticados

- Estruturas condicionais
- Operadores lógicos
- Operações matemáticas
- Variáveis
- Entrada e saída de dados
- Divisão inteira e resto
- Biblioteca `random`
- Lógica de programação
